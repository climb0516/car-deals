# 🚗 车市行情 · 新车与降价

> 买车前看一眼：本地经销商降价榜、新车上市日历、月销量榜

**🌐 在线访问：[https://climb0516.github.io/car-deals/](https://climb0516.github.io/car-deals/)**

---

## 功能

- **顶部要点**：当前城市降幅最大的车、上月销量冠军、近 7 天上市几款新车、下一款即将上市的车（倒计时）
- **降价榜**：8 个城市（杭州默认，另有上海、北京、广州、深圳、成都、武汉、南京）本地经销商报价，每城前 100 个车系；按价位（10 万以下 / 10–20 / 20–30 / 30 万以上）、品牌筛选，按降幅或降价金额排序；显示现价、最高降多少万、降幅；点击跳转懂车帝车系页
- **新车日历**：即将上市（日期、倒计时、预售价）和近期已上市（日期、售价、报道家数），同一车型多家报道已合并；另附爱卡汽车「最新上市」车型列表
- **月销量榜**：近 6 个月可切换，前 30 名，名次较上月升降，新上榜标记
- 右侧：当前城市降价车系最多的品牌、怎么看降价榜、来源状态
- 深色 / 浅色主题，手机适配；选择的城市记在本机

降价信息基于本地经销商报价，「最高降」是车系里优惠最多的一款配置，实际以到店为准。

## 数据来源

| 数据 | 来源 | 说明 |
|---|---|---|
| 降价榜 | 懂车帝排行榜接口 `rank_data?rank_data_type=52&city_name=…` | `descender_price` = 最高降价（万），`count` = 最高降幅（%），`price` = 降后现价区间 |
| 月销量 | 懂车帝排行榜接口 `rank_data_type=11&month=YYYYMM` | `count` = 当月销量 |
| 新车上市 | Google News RSS（「正式上市 售价」「将于 X 月 X 日上市 预售」等） | 从标题提取车型名、价格、上市日期；过滤问答式 SEO 文、盘点类标题 |
| 最新上市（补充） | [爱卡汽车新车频道](https://newcar.xcar.com.cn/) | 车型 + 价格，无日期 |

**限制**：
- 懂车帝接口没有公开文档，榜单类型编号（52 降价、11 销量）为实测结果，改版后对应模块会沿用旧数据并在来源状态里标出
- 懂车帝网页需要登录态，只能用接口；没有可靠的新能源标记，所以销量榜不区分燃油 / 新能源
- 新车信息从新闻标题自动提取，可能有遗漏、车型名不完整或把改款当新车

## 技术架构

```
GitHub Actions（每天北京时间 09:40 / 手动 / 修改爬虫后 push）
  ↓ python scraper.py（只用标准库，约 30 次请求）
  ↓ 8 城降价榜 ×2 页 + 近 6 月销量（已结束月份缓存）+ 新闻 + 爱卡
  ↓ 写入 data.json 并 commit（updated 每次都变 = 心跳，防止定时任务 60 天不活跃被停用）
       ↓
GitHub Pages（index.html 读取 data.json，筛选排序在前端完成）
```
